Workflow: download the CMD, run it on the Veeam Backup & Replication server, import the generated JSON, then download the DOCX report.
Run location: the CMD must run on a Windows host with PowerShell 7 and the Veeam Backup PowerShell module available. The embedded collector is the attached working PowerShell script; its collection logic is not modified by this page.
